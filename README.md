# MONO Finance

Personal finance PWA. Published with GitHub Pages from the `main` branch, repository root.

## Data safety

Financial records are stored locally in the browser, not in GitHub. Export both financial and planning backups before changing domains or reinstalling the PWA. Never commit exported JSON backups.

## Deployment

Settings > Pages > Deploy from a branch > main > /(root).

## Version

1.1.7 (currency converter).
